# PropertySetu — Product Vision

## One-line positioning

**PropertySetu is a guided, accountable property-registration workspace that helps applicants prepare complete submissions and helps authorised officers review them transparently.**

## Why it stands out

Most academic registration projects stop at forms and database records. PropertySetu is designed around the harder real-world problem: reducing confusion while protecting sensitive records and preserving accountability.

### Product principles

1. **Clarity before complexity** — applicants see the next step, required document categories, accepted formats, and current status.
2. **Protection by default** — documents are not public URLs; access is authenticated, authorised, and relationship-checked.
3. **Accountability, not black-box decisions** — officer actions create an audit history with actor, role, time, and details.
4. **Truthful payment experience** — the current workflow is explicitly test-mode; no live payment is claimed.
5. **Human review with structured evidence** — officers review documents individually before completing an application.
6. **Inclusive guidance** — public-facing instructions are simple and educational; legal requirements remain subject to the relevant office and transaction.

## Core experience

```text
Prepare → Create profile → Add property → Upload checklist documents
→ Submit → Test payment → Officer review → Decision → Audit trail
```

## Showcase features

- Applicant and officer role separation
- JWT-protected API access
- Ownership checks across applications, properties, documents, and payments
- Required-document checklist enforcement
- PDF/JPG/JPEG/PNG validation and file-signature checks
- Protected document viewing
- Test-mode payment transition
- Document-by-document officer review
- Persistent accountability history
- Responsive applicant and officer interfaces

## Honest scope

The MVP does not claim government integration, legal approval, live payment collection, OCR, blockchain, fraud detection, public deployment, or production-grade storage compliance. Those are future deployment concerns that require verified infrastructure, contracts, credentials, security review, and operational controls.

## Future product direction

- Secure private object storage with malware scanning and retention policies
- Notification centre for application events
- Accessibility improvements and multilingual guidance
- Office-specific checklist configuration
- Deployment monitoring and incident audit workflows
- Verified payment-provider sandbox integration
- Mobile client using the same secured REST API

## Presentation message

> PropertySetu does not try to replace legal authorities. It makes the preparation and review journey clearer, safer, and more accountable.
